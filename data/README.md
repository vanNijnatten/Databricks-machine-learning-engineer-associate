# Tutorial datasets

Both datasets are **synthetic**: they were generated by
[`src/db_ml_associate/datasets.py`](../src/db_ml_associate/datasets.py) and contain no real people,
customers or houses. They are distributed under the repository's [MIT licence](../LICENSE).

A test (`tests/test_datasets.py`) regenerates both files and checks that they are identical to the
committed versions, so the code and the data cannot drift apart.

## Regenerating

```bash
uv run db-ml-associate datasets generate churn --out data/customer_churn.parquet
uv run db-ml-associate datasets generate house_prices --out data/house_prices.parquet
```

The defaults (seed `42`, 5,000 and 3,000 rows) reproduce the committed files.

## `customer_churn.parquet` — classification

5,000 rows, one per customer. Label: `churned`.

| Column | Type | Meaning | What it is used to teach |
|---|---|---|---|
| `customer_id` | int | Primary key (1…5000) | Feature-table primary keys |
| `tenure_months` | int | Months as a customer (1–72) | Numeric feature |
| `contract_type` | string | `month-to-month`, `one-year`, `two-year` | Low-cardinality categorical, one-hot encoding |
| `payment_method` | string | `card`, `bank_transfer`, `electronic_check`, `mailed_check` | Categorical feature |
| `city` | string | ~800 possible cities (`city_0000`…) | High-cardinality categorical: when one-hot encoding is a bad idea |
| `monthly_charges` | float | Monthly bill; **exactly 5 % missing** | Mean/median imputation |
| `data_usage_gb` | float | Monthly data usage; right-skewed; **4 % missing** | Median vs mean imputation, log transform |
| `support_calls` | int | Support calls last quarter; a few **injected outliers** (15–25) | Outlier removal (standard deviation, IQR) |
| `churned` | int | 1 if the customer left (**exactly 10 %**) | Class imbalance, metric choice |

## `house_prices.parquet` — regression

3,000 rows, one per sold house. Target: `price`.

| Column | Type | Meaning | What it is used to teach |
|---|---|---|---|
| `house_id` | int | Primary key (1…3000) | Feature-table primary keys |
| `neighborhood` | string | 12 neighbourhoods | Categorical feature |
| `living_area_sqm` | float | Living area in m² | Strongest numeric predictor |
| `bedrooms` | int | Number of bedrooms (1–7) | Correlated features |
| `year_built` | int | Construction year | Numeric feature |
| `has_garage` | int | 1 if the house has a garage | Binary feature |
| `condition` | string | `poor`, `fair`, `good`, `excellent` | Ordinal categorical |
| `lot_size_sqm` | float | Plot size; right-skewed with a few 10× outliers; **5 % missing** | Imputation, outliers |
| `price` | float | Sale price; **right-skewed** (skewness ≈ 1.2, ≈ 0 after `log1p`) | Log transform of the target and back-transforming predictions |
