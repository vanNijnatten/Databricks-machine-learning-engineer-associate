# Databricks Certified Machine Learning Associate — Study Guide

A book, hands-on tutorials and practice exams to prepare for the **Databricks Certified Machine
Learning Associate** exam in two to three weeks.

- **Exam guide targeted**: version of 2025-03-01 ([official PDF](https://www.databricks.com/sites/default/files/2025-02/databricks-certified-machine-learning-associate-exam-guide-1-mar-2025.pdf)).
  Check the [certification page](https://www.databricks.com/learn/certification/machine-learning-associate)
  for a newer guide two weeks before your exam.
- **Platform targeted**: Databricks Runtime 18 LTS for Machine Learning, documentation snapshot of
  2026-10-14 — see [`runtime.toml`](../runtime.toml).

## How to use this book

1. Read the [introduction](introduction.md) to set up a workspace and pick a study plan.
2. Follow a [study plan](appendix-c-study-plans.md): the plans give the **recommended reading order**
   (foundations first). Chapters are numbered in exam-guide order so you can map them to the exam
   sections, but you do not have to read them in numeric order.
3. For each chapter: read it, run its tutorial notebook in `notebooks/`, then answer its review
   questions without looking at the answers.
4. Take both [practice exams](appendix-d-practice-exams.md) under exam conditions and revisit the
   chapters linked to your missed questions.
5. Revise with the [cheat sheet](appendix-b-cheat-sheet.md) and the
   [exam vs current platform](appendix-a-exam-vs-platform.md) list.
