# Appendix A — Exam vs current platform

The exam guide (version 2025-03-01) was written for the platform of early 2025. This table lists every
place where the exam's wording and today's Databricks platform (documentation snapshot
2026-10-14) differ, **what to answer on the exam**, and where the book explains it.

Generated by `uv run db-ml-associate book render-appendix-a` from
[`exam/platform-changes.yaml`](exam/platform-changes.yaml) — edit that file, not this page.

| Exam term | Current platform | Change | What the exam expects | Objectives | Explained in | Sources |
|---|---|---|---|---|---|---|
| Hyperopt fmin / SparkTrials | Optuna (single node, parallel with joblib) or Ray Tune (distributed) | deprecated | Hyperopt is still on the exam: fmin(fn, space, algo=tpe.suggest, max_evals, trials) minimises the objective; SparkTrials parallelises single-node models (needs classic compute). It is not preinstalled after 16.4 LTS ML (%pip install hyperopt). | S3.05, S3.06, S3.07 | [ch. 10](10-validation-and-tuning.md) | [hyperparameter-tuning](https://docs.databricks.com/aws/en/machine-learning/automl-hyperparam-tuning/), [dbr-18-lts-ml](https://docs.databricks.com/aws/en/release-notes/runtime/18ml) |
